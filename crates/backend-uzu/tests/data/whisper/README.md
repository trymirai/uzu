# Whisper audio reference provenance

The PCM and mel values are captured from OpenAI Whisper's external contract,
not generated by Uzu.

- Upstream commit: `5f86d1d86363843179951550570367b37c5d6f78`
- Source: <https://github.com/openai/whisper/blob/5f86d1d86363843179951550570367b37c5d6f78/tests/jfk.flac>
- Source SHA-256: `63a4b1e4c1dc655ac70961ffbf518acd249df237e5a0152faae9a4a836949715`
- PCM SHA-256: `64ff79526fbd6224274ee39466eb350d0b946824d95b54b632efb63da32a54ab`

The PCM capture is the 200 ms interval beginning at 1.0 seconds, decoded as
16 kHz mono signed little-endian 16-bit samples:

```sh
ffmpeg -v error -i jfk.flac -ss 1.0 -t 0.2 -ac 1 -ar 16000 -f s16le jfk_1s_200ms.s16le
xxd -p -c 64 jfk_1s_200ms.s16le > jfk_1s_200ms.s16le.hex
```

The reference used `openai-whisper` at the pinned commit (package version
`20250625`), PyTorch `2.13.0`, and NumPy `2.4.6`. This script records every
mel bin at frames 0, 4, 8, 12, 16, 20, and 25, spanning signal, the
signal/padding boundary, and padding:

```python
from pathlib import Path

import numpy as np
import whisper

frames = [0, 4, 8, 12, 16, 20, 25]
pcm = np.fromfile("jfk_1s_200ms.s16le", dtype="<i2").astype(np.float32) / 32768.0
audio = whisper.pad_or_trim(pcm)

for n_mels in (80, 128):
    mel = whisper.log_mel_spectrogram(audio, n_mels=n_mels).cpu().numpy()
    lines = [f"# frame<TAB>{n_mels} mel bins in ascending bin order"]
    for frame in frames:
        values = ",".join(format(float(value), ".9g") for value in mel[:, frame])
        lines.append(f"{frame}\t{values}")
    Path(f"jfk_1s_200ms.mel{n_mels}.tsv").write_text("\n".join(lines) + "\n")
```
